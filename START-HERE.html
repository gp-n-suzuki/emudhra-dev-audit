eMudhra 開発環境診断

ソース版を実行する

このフォルダーには同梱Pythonや「診断を開始」はありません。Python 3.8以上を用意し、このフォルダーでターミナルを開いて実行してください。配布版を受け取った方は、展開先の docs/使い方.html をご覧ください。

1. コマンドを実行する

Windows PowerShell

Python Launcherを導入している場合の例です。py がない場合の指定方法は詳細ガイドにあります。

py -3 -B audit.py --out ./report

macOS / Linux

python3 -B audit.py --out ./report

外部通信を省く場合は --offline を追加します。同じ --out を再利用すると結果を上書きします。--out を省略した場合は、現在のフォルダーの emudhra-report-日時/ へ保存します。

macOS / Linuxの追加オプションを選ぶ

次のコマンドは run-checks.sh を使います。Python 3.8以上をPATHで利用できる環境が必要です。Windowsでは上記のPowerShellコマンドを使ってください。

このソースフォルダーを現在のディレクトリにして実行します。

2. 結果を開く

通常は数分程度で終了し、保存先が表示されます。上記の例では report/report.html を手動でブラウザで開いてください。

ツール → 導入先の順に開き、「次の行動」「版の判定」「通信の検証」「不足情報と次の確認」を読みます。最新版でも通信が未検査なら追加確認が残ります。

表示サンプルを開く（実際の診断結果ではありません）

実行前の注意

通常は導入済みの対象コマンドを実行し、外部へHTTPS接続します。組織のネットワーク利用ルールを確認してください。管理者権限は不要です。診断はレポートと一時ファイルを作りますが、対象ソフトの更新・設定変更・証明書ストア変更は行いません。

判定基準は2026-11-02時点の固定データです。結果は検査した導入先・接続先に限り、PC全体の安全性を保証しません。共有前にレポート中のローカルパスなどを確認してください。

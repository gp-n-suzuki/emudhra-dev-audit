# eMudhra 開発環境診断 1.0

PCにある開発ツールのバージョン、証明書検証の設定、HTTPS通信を調べ、更新・設定修正・追加確認が必要な対象を表示するツールです。診断基準日は **2026-11-02** です。

## はじめる

- **配布版を受け取った方**：[かんたん操作ガイド](START-HERE-ja.md)をご覧ください。圧縮ファイルをすべて展開し、「診断を開始」を実行します。Pythonの事前インストールは不要です。
- **このソースフォルダーから使う方**：Python 3.8以上が必要です。このフォルダーで次を実行し、生成された `report/report.html` をブラウザで開きます。

```bash
# macOS / Linux
python3 -B audit.py --out ./report
```

```powershell
# Windows PowerShell（Python Launcherを導入している場合）
py -3 -B audit.py --out ./report
```

このソースフォルダーには、配布用の起動ファイル「診断を開始」や同梱Pythonはありません。外部通信を行わない場合は、上記コマンドに `--offline` を追加してください。同じ `--out` を使うと結果を上書きします。

## 対応環境と結果

配布の対象は **Windows・macOS・Linuxのx64 / arm64** です。Windowsはzip、macOS・Linuxはtar.gzです。Linux用ランタイムはGNU/Linux向けです。最小OSバージョンや全ディストリビューションでの動作は確定していません。[OS・CPU別の検証範囲](VALIDATION-ja.md)を確認してください。

結果はツールごとの「次の行動」から確認します。「版の判定」と「通信の検証」は別の結果です。最新版でも通信が未検査なら追加確認が残ります。[結果の読み方](ACTION-PRESENTATION-ja.md)と[表示サンプル](sample-report.html)も参照できます。サンプルは実際のPCの診断結果ではありません。

## 実行前に確認すること

通常の診断は外部の通常サイト・証明書検証用サイト等へ接続し、導入済みの対象コマンドを実行します。ネットワーク利用のルールを確認してから実行してください。診断はレポートと一時ファイルを作りますが、対象ソフトの更新、設定変更、証明書ストアの変更は行いません。管理者権限は不要です。

「検査した範囲で問題なし」は、表示された導入先・接続先・観測日時に限る結果で、PC全体の安全保証ではありません。参照データは固定で、最新情報へ自動更新されません。レポートにはローカルパスなどが含まれるため、共有前に内容を確認してください。
